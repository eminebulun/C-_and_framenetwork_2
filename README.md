# .NET Framework – Part 2 Coursework

This repository includes a series of **C# projects** built within the **.NET Framework** environment.  
Each directory contains a dedicated exercise aimed at improving coding fluency, logical thinking, and practical software design.

---

## Project Structure

- `asp/` – An introductory **ASP.NET MVC** web project focusing on routes, controllers, and model integration.  
- `final/` – The final assignment combining multiple programming concepts such as OOP, data management, and user input validation.  
- `method/` – Exercises focused on **methods**, covering parameters, return types, and overloading techniques.  
- `operators/` – Compact programs demonstrating arithmetic, logical, and comparison operators through simple examples.  
- `polymorphism/` – Hands-on work with **inheritance**, abstract classes, and polymorphism for adaptable code design.  
- `portfolyo/` – A final project that consolidates all previous work into a personal, organized project showcase.

> The file and folder structure directly reflects the organization of this repository.
